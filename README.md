# 🛡️ Decentralized Academic Certificate Verification System

Issue tamper-proof academic certificates on the blockchain and verify them in
seconds with a QR code. Built with Solidity, Hardhat, IPFS (Pinata), React, and
ethers.js + MetaMask.

---

## ✨ Features

- **Smart contract** (`CertificateVerification.sol`, ERC-721 based) lets you issue, verify and revoke
  certificates. A college **whitelist** is controlled by the contract owner.
- **IPFS storage**: certificate PDFs are pinned to IPFS through Pinata, and the returned CID is stored on-chain.
- **Issue certificates**: a whitelisted college connects MetaMask, uploads a PDF, records the certificate
  on-chain and gets a **downloadable QR code**.
- **Batch issuance**: upload a CSV (`enrollmentNo,studentName,collegeName`), preview the rows and
  issue them all, with a progress bar. A template CSV can be downloaded from the page.
- **Verify certificates**: anyone can enter a certificate ID (or scan the QR code) and see
  **Genuine / Revoked / Not Verified**, with a link to the PDF on IPFS.
- **Zero-knowledge selective disclosure** (`/zkproof`): a student generates a shareable proof that
  reveals only the attributes they choose (for example "graduated" or "CGPA above X") without exposing
  the whole certificate. An employer pastes the proof, or opens the link, to verify it.
- **Analytics dashboard** (`/analytics`): totals for issued and revoked certificates, built from
  contract events (or local data in demo mode).
- **Demo mode** (`REACT_APP_DEMO_MODE=true`): simulates the blockchain and IPFS entirely in the
  browser, so the whole flow can be shown with no wallet, node or Pinata keys.
- **MetaMask integration**: wallet connection and automatic network switching.

## 🚀 Setup & run

### Prerequisites
- Node.js 18+ and npm
- [MetaMask](https://metamask.io) browser extension
- A free [Pinata](https://pinata.cloud) account (API key + secret)

### ⚡ Quickest path — one command (recommended for the demo)

From the project root, run:

```powershell
powershell -ExecutionPolicy Bypass -File start-demo.ps1
```

This installs deps (first run), compiles the contract, starts a local blockchain,
deploys + **auto-whitelists** the demo wallet, **auto-syncs** the contract address
and ABI into the frontend, and launches the React app. The script then prints the
MetaMask network + test-account details to import. (Add real Pinata keys to
`frontend/.env` for the PDF→IPFS step; everything else works without them.)

Prefer to do it by hand? Follow Part A + Part B below.

### Part A — Smart contract (manual)

```bash
cd contract
npm install
npx hardhat compile          # generates the ABI

# In terminal 1: start a local blockchain
npx hardhat node             # prints 20 funded test accounts + private keys

# In terminal 2: deploy to that local node
npx hardhat run scripts/deploy.js --network localhost
# → copy the printed "Contract Address"
```

After deploying you must **whitelist a college wallet** so it can issue. The
quickest way for the demo is the Hardhat console:

```bash
npx hardhat console --network localhost
> const c = await ethers.getContractAt("CertificateVerification", "<CONTRACT_ADDRESS>")
> await c.addCollege("<YOUR_METAMASK_ADDRESS>")
```

### Part B — Frontend

1. Copy `frontend/.env.example` to `frontend/.env` and fill it in:
   ```
   REACT_APP_PINATA_API_KEY=...        # from Pinata
   REACT_APP_PINATA_API_SECRET=...     # from Pinata
   REACT_APP_CONTRACT_ADDRESS=0x...    # from the deploy step
   REACT_APP_CHAIN_ID=31337            # local Hardhat
   REACT_APP_DEMO_MODE=false           # true = no wallet/IPFS needed
   ```
2. Make sure `frontend/src/contract-abi.json` exists (it is regenerated whenever
   you run `npx hardhat compile` in `contract/`).
3. Run it:
   ```bash
   cd frontend
   npm install
   npm start                 # opens http://localhost:3000
   ```
4. In MetaMask: add the **Localhost 8545 / chainId 31337** network and import one
   of the private keys printed by `npx hardhat node` (use the one you whitelisted).

## 🎬 Demo walkthrough

1. Open the app → **Home** explains the system.
2. Click **Connect Wallet** → approve in MetaMask.
3. Go to **Issue** → fill in ID / student / college, choose a PDF → **Issue**.
   - PDF uploads to IPFS, MetaMask prompts to confirm the on-chain transaction,
     and a **QR code** appears.
4. Go to **Verify** → enter that same certificate ID (or open the QR link) →
   shows **✅ Genuine** with all details and the IPFS link.
5. Enter a made-up ID → shows **❌ Not Verified** to prove forgery is caught.

## 📝 Notes

- **Polygon Mumbai is offline.** Polygon sunset the Mumbai testnet in 2024, so its
  faucets/RPCs no longer work. This project therefore demos on a **local Hardhat
  node** (fully offline, reliable) and is configured to deploy to **Polygon Amoy**
  (Mumbai's official replacement, chainId 80002) for the final review.
- **Never commit real keys.** Only the `.env.example` files are committed. Your real
  `.env` files are git-ignored.
